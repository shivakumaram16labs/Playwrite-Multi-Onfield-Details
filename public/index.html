Upload your on-field Excel sheet

The server will render each URL once, cache a PNG snapshot, and reuse it permanently until the cache folder is deleted.

Expected column names include onfield_link or onfiled_link.

How to use

  1. Click Upload Excel and choose an Excel, CSV, or TSV file.
  2. Choose the worksheet and the column containing the allowed page links.
  3. Click Apply. The gallery rebuilds from that column without uploading again.
  4. Use Previous/Next or scroll through the records. The first 10 records are queued, then the configured preload range is added when you approach the end of the loaded range.

Why snapshots?

The server opens each page once in Playwright and saves a full-page PNG. The browser displays that PNG instead of keeping many live pages open, preventing iframe reloads and reducing browser memory use.

API endpoints

POST /api/upload
Uploads a workbook, reads its sheets and headers, and creates a session.
GET /api/session/:id
Returns the current session links and workbook metadata.
POST /api/session/:id/select
Reads links from a selected sheet and column without re-uploading the workbook.
GET /api/session/:id/render/:index
Returns metadata and the cached PNG URL for one record.
GET /api/cache/status
Returns the number of cached snapshots.
DELETE /api/cache
Deletes all generated PNG and metadata cache files so pages can be captured again.

Only ALLOWED_HOST URLs are rendered. This protects the screenshot service from being used to request unrelated internal or external sites.
